### 01 / About

I work both sides of the line. I started in security through **malware analysis and offensive tooling** — Kali, exploitation basics, understanding how systems fail before I ever thought about defending them. That's shaped how I build and how I secure: I don't design a system without first asking how I'd break it.

Day to day, I'm a **full-stack developer** — FastAPI, Django, Flask, React, PostgreSQL — building products with real users and real data. In parallel, I'm formalizing the defensive side of that same instinct, working toward **SOC Analyst → Incident Response / Threat Hunter**, with a home lab (Wazuh, VirtualBox, Kali) and the offensive-security background most Blue Teamers arrive without.I am naturally gifted with managerial skills so I'm working on furthering in Project Management too. 

`Full-Stack Engineering` · `Offensive Security Fundamentals` · `Blue Team / SOC` · `Secure SDLC` · `Agile & Kanban` · `AI-integrated tooling`
