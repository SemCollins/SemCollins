An AI tool for detecting Ghanaian-context scams — MoMo fraud, fake job offers, phishing, romance scams. Built on FastAPI, PostgreSQL, and an LLM backend.

**⛪ Church Connect Hub** — *Full-Stack / Web App*
A web-based church management system built with Flask, Supabase, and HTML/CSS/JS, backed by a full technical specification.

**📝 Re-Mind → Exam Paper Generator** — *EdTech / AI*
A GES curriculum-aligned exam paper generator, now a React app integrated with the Claude API — evolved from an earlier Python + Gemini prototype.

**🏫 Academia** — *Secure SDLC Coursework Project*
A Student Information Management System built end-to-end through the Secure Software Development Life Cycle — auth, RBAC, input validation, and a full security test report. `academia-orcin-zeta.vercel.app`

**🧪 Home SOC Lab** — *Blue Team / Detection Engineering*
A self-built lab running Wazuh SIEM, Kali Linux, and Windows VMs on VirtualBox — used for log analysis, incident-handling practice, and CTF-style detection exercises.
